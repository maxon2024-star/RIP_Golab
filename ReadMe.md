# Заявочная система на услуги (РИП 2026)

## Описание проекта
Учебный проект по курсу "Разработка Интернет Приложений" (РИП) 2026 года. Система представляет собой веб-приложение для оформления заявок на услуги в выбранной предметной области с архитектурой, включающей бэкенд, фронтенд, нативное приложение и асинхронный сервис.

## Технологический стек
- **Бэкенд**: Go (веб-сервис с REST API)
- **Фронтенд**: React + Redux Toolkit + Axios + React-Bootstrap
- **База данных**: PostgreSQL
- **Хранилище файлов**: Minio
- **Кэширование/сессии**: Redis
- **Нативное приложение**: Tauri (на основе React)
- **Асинхронный сервис**: Дополнительный сервис на другом языке (Django/NestJS)
- **Документация**: Swagger, StarUML/draw.io
- **Контейнеризация**: Docker Compose

## Структура проекта
Проект состоит из нескольких компонентов:
1. **Веб-сервис (Go)** - основное API приложения
2. **Фронтенд (React)** - SPA интерфейс
3. **Нативное приложение (Tauri)** - десктопное приложение
4. **Асинхронный сервис** - дополнительный сервис для отложенных операций

## Предметная область
### В разработке

**Важно**: Все названия сущностей, полей и методов должны соответствовать выбранной предметной области.

## Требования к реализации
- 4-6 кастомных полей в основных сущностях
- Уникальный дизайн (цветовая схема, стили)
- Реальные данные по тематике
- Строгое именование по предметной области (никаких общих названий)

## Этапы разработки (лабораторные работы)
1. **Лаб 1**: Дизайн в Figma, базовые шаблоны Django/Go
2. **Лаб 2**: Проектирование БД, подключение PostgreSQL
3. **Лаб 3**: Создание REST API веб-сервиса
4. **Лаб 4**: Авторизация, сессии, Swagger
5. **Лаб 5**: Базовый фронтенд на React
6. **Лаб 6**: Redux, адаптивность, PWA, Tauri
7. **Лаб 7**: Полный интерфейс пользователя
8. **Лаб 8**: Асинхронный сервис, real-time обновления
